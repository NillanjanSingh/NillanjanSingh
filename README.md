## 🚀 Featured Projects

### 🧠 [VECS — High-Performance Vector Store](https://github.com/NillanjanSingh/vecs)

A high-performance **out-of-core vector search engine written in C++**.

* Memory-mapped storage using POSIX `mmap`
* Zero-copy text serialization
* `llama.cpp` embedding pipeline
* Custom thread pool and thread-local model instances
* HNSW approximate nearest-neighbor search
* Fine-grained node locking

**C++ · POSIX · CMake · llama.cpp · HNSW**

---

### ⚙️ [VERSE — RISC-V Architecture Simulator](https://github.com/NillanjanSingh/verse)

A **cycle-accurate RV32IM processor simulator written in Rust**.

* 5-stage pipelined CPU
* Custom macro-assembler
* Pseudo-instruction expansion
* Memory-Mapped I/O
* Configurable L1/L2 cache hierarchy
* Virtual memory trace replay
* Reproducible Nix environment

**Rust · RISC-V · Computer Architecture · Nix**

---

### 📈 [Overnight Return Predictor](https://github.com/NillanjanSingh/overnight-return-predictor)

A leakage-free quantitative pipeline for forecasting **overnight equity returns**.

* 208-asset universe
* Intraday data processing
* OLS and Logistic Regression
* EWMA features
* Rolling kurtosis and tail-risk scoring
* Custom next-open execution simulator
* Transaction-cost-aware backtesting

**Python · NumPy · Pandas · SciPy · Scikit-learn**
